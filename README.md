# Hemraj Thakare Portfolio

Personal portfolio website built with Next.js, React, and Tailwind CSS.

## Highlights

- Clean single-page portfolio layout
- Custom profile photo and internship letter
- GitHub, LinkedIn, and Facebook integration
- Education, experience, projects, and contact sections
- Responsive design for desktop and mobile

## About

This portfolio presents Hemraj Thakare as an engineering student and software developer focused on learning, building practical projects, and growing through real-world experience.

## Tech Stack

- Next.js
- React
- Tailwind CSS
- Sass

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.
